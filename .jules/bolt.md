## 2026-08-09 - Memoizing Sliced Lists and FlatMap Hook Derivations in Polled UI
**Learning:** When using polling queries (like `useQuery` with `refetchInterval`), any downstream custom React hook returning newly mapped or flat-mapped collections (e.g., `notificationsQuery.data?.pages.flatMap(...)`) produces a new array reference on every single hook run. This completely breaks children's memoization (`React.memo`) because the reference is always fresh. Memoizing both the collection within the hook and subsequent slice calculations (e.g., `notifications.slice(0, 10)`) is critical to ensure stable array references and avoid expensive list re-renders.
**Action:** Always wrap array transformations (`flatMap`, `filter`, `slice`, `map`) inside custom hooks or components in `useMemo` when returning them to subcomponents, and combine this with `React.memo` for maximum rendering performance.
