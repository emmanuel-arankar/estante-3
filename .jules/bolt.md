## 2026-07-25 - Notification List Reference Stability
**Learning:** In polling interfaces, rendering derived arrays using inline operations like `flatMap` or `.slice()` inside hooks and components triggers constant garbage collection and breaks downstream rendering performance. Wrapping `flatMap` derivations inside custom hooks with `useMemo` ensures that reference checks on consumers remain stable, eliminating rendering overhead. Wrapping lists and list items in `React.memo` completes the optimization chain by stopping renders when notifications list values actually stay the same during background polling.
**Action:** Always memoize derived collection structures at the source (custom hooks) and down-level slices, and pair them with `React.memo` on list item elements when dealing with active polling/frequent updates.
